# HyperDAG-Bench

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](http://makeapullrequest.com)

Public benchmark suite for HyperDAG Protocol's HAL (Hallucination Assessment Layer). Reproducible methodology, public datasets, transparent results.

## Quick Start
```bash
npm install
npx ts-node src/runners/truthfulqa-runner.ts --sample-size 100
```

## Supported Datasets
- **TruthfulQA** (Active)
- HaluEval (Parking lot)
- NyayaverifyBench (Parking lot)
